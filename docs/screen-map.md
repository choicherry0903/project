# 화면 구성

| 화면 | 경로 | 현재 범위 |
| --- | --- | --- |
| 고객 | /customers | DB 전체 조회, 건수와 빈 목록 표시, 등록 화면 및 상세 미리보기 이동 |
| 고객 등록 | /customers/regform | 고객·현장·상담 항목 입력, 행 추가·삭제, 검증 및 저장 |
| 고객 상세 | /customers/detail | projectId로 고객·현장·상담 조회, 수정·삭제 화면 진입 |
| 고객 수정 | /customers/{projectId}/edit | 등록 폼 재사용, 고객·현장·상담 편집 및 저장 |
| 고객 삭제 확인 | /customers/{projectId}/delete | 고객의 모든 현장 숨김 안내 및 확인 후 보관 처리 |
| AI 상담 정리 | /aicounsult | 기존 골격 유지, AI 연결 없음 |

왼쪽 메뉴는 AI 상담 정리, 고객, 고객 상세 순서입니다. 로그인 후 AI 상담 정리 화면이 열립니다.
등록은 고객 목록의 고객 등록 버튼으로 이동합니다. 목록의 현장명을 클릭하면 해당 상세로 이동합니다. 고객 상세에는 고객 > 상세 경로를 표시합니다.
등록 저장은 POST /customers/insertCustomer에서 처리합니다. 수정·삭제는 각 화면과 동일한 URL의 POST 요청으로 처리합니다.
