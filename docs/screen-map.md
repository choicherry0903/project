# 화면 구성

| 화면 | 경로 | 현재 범위 |
| --- | --- | --- |
| 고객 | /customers | DB 전체 조회, 건수와 빈 목록 표시, 등록 화면 및 상세 미리보기 이동 |
| 고객 등록 | /customers/regform | 고객명·연락처·현장명·주소 입력 화면만 제공 |
| 고객 상세 | /customers/detail | 상담·견적·계약·자재·시공·검수와 수금 일정의 HTML 미리보기, 조회·저장 없음 |
| AI 상담 정리 | /aicounsult | 기존 골격 유지, AI 연결 없음 |

메뉴는 고객, 고객 상세, AI 상담 정리입니다.
등록은 고객 목록의 고객 등록 버튼으로 이동합니다. 고객 상세에는 고객 > 상세 경로를 표시합니다.
등록 저장·수정·삭제는 사용자가 이어서 구현하며 해당 경로/쿼리는 제공하지 않습니다.
