# 화면 구성

| 화면 | 경로 | 현재 범위 |
| --- | --- | --- |
| 고객·현장 목록 | /projects | DB 전체 조회, 건수와 빈 목록 표시, 등록 화면 이동 |
| 고객·현장 등록 | /projects/new | 고객명·연락처·현장명·주소 입력 화면만 제공 |
| 현장 상세 | /projects/detail | 기존 골격 유지, 데이터 조회 없음 |
| AI 상담 정리 | /consultations/ai | 기존 골격 유지, AI 연결 없음 |

상단 메뉴는 고객·현장 목록, 현장 상세, AI 상담 정리의 세 개를 유지합니다.
등록은 목록의 고객·현장 등록 버튼으로 이동합니다.
등록 저장·수정·삭제는 사용자가 이어서 구현하며 해당 경로/쿼리는 제공하지 않습니다.
